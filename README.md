# 📊 Análise de Vendas com Python

Projeto desenvolvido durante meus estudos em Análise e Desenvolvimento de Sistemas (ADS), com o objetivo de praticar conceitos de banco de dados, análise de dados e visualização de informações.

## 🛠️ Tecnologias utilizadas

* Python
* SQLite
* Pandas
* Matplotlib
* Seaborn
* Google Colab

## 📌 Sobre o projeto

O projeto utiliza uma base de dados de vendas armazenada em um banco SQLite.

Os dados foram carregados utilizando Python e analisados com a biblioteca Pandas. Também foram utilizados Matplotlib e Seaborn para criar gráficos e facilitar a interpretação dos resultados.

## 🔎 Análises realizadas

Durante o projeto foram realizadas algumas análises, como:

* Consulta dos dados armazenados no SQLite;
* Verificação das informações do DataFrame;
* Identificação de valores ausentes;
* Estatísticas básicas das vendas;
* Cálculo do valor médio das vendas;
* Identificação da maior e menor venda;
* Análise das vendas por mês;
* Criação de gráficos para visualização dos resultados;
* Análise da distribuição dos valores das vendas.

## 📈 Principais resultados

A análise mostrou um faturamento total de R$ 8.800,00 no conjunto de dados utilizado.

O valor médio das vendas foi de aproximadamente R$ 628,57.

A maior venda registrada foi de R$ 1.500,00, enquanto a menor foi de R$ 150,00.

A categoria de Eletrônicos apresentou o maior faturamento entre as categorias analisadas.
