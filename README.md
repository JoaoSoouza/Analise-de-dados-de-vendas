analise-vendas-python
📊 Mais um projeto concluído durante meus estudos em Análise e Desenvolvimento de Sistemas.

Neste projeto, trabalhei com uma base de dados de vendas utilizando:

🐍 Python
🗄️ SQLite
🐼 Pandas
📈 Matplotlib
📊 Seaborn

A atividade envolveu a criação e consulta de um banco de dados, organização das informações com Pandas e criação de gráficos para analisar os resultados.

Uma das coisas que achei mais interessante foi conseguir transformar os dados em gráficos e, a partir deles, identificar quais categorias tiveram melhor desempenho.

Ainda estou no começo da minha jornada na área de tecnologia, mas cada projeto está ajudando a entender melhor como programação e análise de dados podem ser utilizadas na prática.
